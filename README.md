# Mastodonte Gestão

App da Associação Mastodonte (PWA, arquivo único `index.html` + Supabase).

- **Afiliados**: cadastro (nome, CPF, telefone, endereço, valor da doação), situação em dia / vencendo / **atrasado em vermelho**, cobrança por WhatsApp.
- **Importar extrato** (Excel/CSV/PDF): baixa automática por CPF, sugestões por nome, saídas categorizadas, sem duplicar.
- **Financeiro**: entradas, saídas, categorias, divisão de boletos agrupados entre afiliados.
- **Eventos**: planejamento, tarefas, orçamento x gasto.
- **Acesso**: só e-mails liberados pelo adm (Configurações). Adm inicial: mastodontesjrp2017@gmail.com.

Banco: `supabase.sql` (projeto `cknzysljezvpazonvibb`).
